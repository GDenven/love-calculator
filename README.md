# love-calculator


💖 Love Calculator

A fun, simple web application that calculates the "love compatibility" percentage between two people. Just enter two names and find out how much they love each other!

Disclaimer: This app uses JavaScript's Math.random() function, meaning the results are completely random and purely for entertainment purposes!

✨ Features

Simple Interface: Just type in two names and click a button.

Instant Results: Generates a random compatibility percentage immediately.

Lightweight: Fast, static website with no backend or database required.

🛠️ Built With

HTML5 – Structure of the web page

CSS3 – Styling and layout

JavaScript – Logic and random percentage generation (Math.random())

🚀 How to Run Locally

Clone this repository:

git clone https://github.com/your-username/your-repo-name.git


Navigate to the project folder.

Open index.html in any web browser.
